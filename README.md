# Automação de Análise Estatística Descritiva em Linguagem R

## 📌 Visão Geral
Este projeto acadêmico implementa um script automatizado em Linguagem R para a realização de um ciclo completo de Estatística Descritiva, cobrindo o tratamento de dados não agrupados e dados agrupados em classes. O objetivo principal foi construir um fluxo reprodutível que gera análises matemáticas, plota gráficos de dispersão e exporta um relatório executivo final em PDF diretamente via código.

## 🛠️ Conceitos e Métodos Estatísticos Aplicados
* **Medidas de Posição e Dispersão:** Cálculo automático de Média, Mediana, Amplitude Total, Quartis e Coeficientes de Variação Amostrais e Populacionais.
* **Tratamento de Dados Agrupados:** Determinação automatizada de classes utilizando a Regra de Sturges e estimativa de Moda por meio da Fórmula de Czuber.
* **Visualização Avançada (R Base):** Geração e exportação em lote de 7 gráficos analíticos (Histogramas, Ogivas de frequência acumulada, Polígonos de frequência e Boxplots com identificação de outliers por Critério de Tukey).
